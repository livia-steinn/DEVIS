# 🗄️ BCD - Banco de Dados

## 📘 Visão Geral

Esta pasta reúne os materiais, atividades, scripts e projetos desenvolvidos na disciplina de BCD, que aborda os fundamentos de banco de dados relacionais, modelagem conceitual, lógica e física, além da criação e manipulação de dados em SQL.

Durante o trimestre, foram trabalhados conceitos essenciais para entender como os dados são estruturados, armazenados e relacionados dentro de um sistema. A disciplina também preparou a base para a criação de bancos de dados funcionais e organizados, aplicados em projetos práticos.

---

## 🎯 Objetivos da Disciplina

- Compreender a estrutura de bancos de dados relacionais
- Entender entidades, atributos e relacionamentos
- Modelar dados de forma conceitual e lógica
- Criar e manipular tabelas com SQL
- Aplicar os conhecimentos em projetos reais e práticos

---

## 🗂️ Estrutura da Pasta

### 📚 Aulas

- `Aula_05/`  
  Primeira etapa prática da disciplina, com introdução aos conceitos básicos de banco de dados e estrutura inicial de scripts SQL.

- `Aula_06/`  
  Desenvolvimento de atividades envolvendo criação de bancos, tabelas e modelagem inicial de estruturas relacionais. Também inclui arquivos de script com comandos SQL.

- `Aula_07/`  
  Aprofundamento na modelagem de relacionamentos entre entidades. Nesta aula foram trabalhados modelos conceitual, lógico e físico, além de cardinalidades e integração de estruturas.

- `Aula_08/`  
  Continuação da prática em SQL, com foco em comandos de manipulação de dados, como inserção, atualização e consulta de registros.

### 🧠 Modelagem

- `Conceitual/`  
  Contém modelos conceituais de banco de dados desenvolvidos em brModelo. Esses arquivos representam as entidades, atributos e relacionamentos do sistema antes da implementação em SQL.

- `Lógico/`  
  Pasta com os modelos lógicos, representando a organização das tabelas e suas relações de forma mais próxima da estrutura funcional do banco.

### 🏢 Projeto

- `Projeto - SMARTCOFFE/`  
  Projeto principal da disciplina, relacionado à criação de um banco de dados para uma cafeteria ou sistema de alimentação. Nesta pasta estão os modelos conceitual, lógico e físico, além do script SQL completo do projeto.

### 🧾 Scripts

- `Scripts/`  
  Contém arquivos SQL prontos para criação de bancos, tabelas e manipulação de dados. Esses scripts servem como base para estudos, exercícios e entregas práticas.

## ▶️ Como Usar

1. Abra a pasta da aula ou do projeto desejado.
2. Consulte os arquivos `.sql` para visualizar os scripts de criação e manipulação.
3. Para modelos conceituais e lógicos, abra os arquivos `.brM` com o BrModelo.
4. Execute os scripts em um banco de dados relacional ou use os arquivos como material de estudo.
