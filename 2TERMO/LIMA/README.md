# 🌐 LIMA - Linguagens de Programação Web

## 📘 Visão Geral

Esta pasta reúne os materiais, exercícios, atividades e projetos desenvolvidos na disciplina de LIMA, durante o 2º termo. A disciplina teve como foco principal o estudo de HTML e CSS, com ênfase na construção de páginas web estruturadas, visualmente organizadas e práticas para uso real.

Ao longo do trimestre, foram explorados conceitos básicos e avançados de desenvolvimento front-end, como estrutura de documentos, semântica, formatação visual, organização de conteúdo e criação de interfaces com finalidade acadêmica e profissional.

---

## 🎯 Objetivos da Disciplina

- Compreender a estrutura de páginas em HTML
- Aplicar estilos e layouts com CSS
- Organizar informações em páginas web de forma clara
- Desenvolver projetos visuais com foco em usabilidade
- Praticar criação de interfaces com elementos e conteúdos reais

---

## 🗂️ Estrutura da Pasta

### 📚 Aulas

- `Aula01/`  
  Primeira introdução à disciplina. Nessa etapa, foram trabalhados conceitos iniciais de HTML e CSS, além da criação de páginas simples com títulos, textos, listas, imagens e estilos básicos.

- `Aula02/`  
  Aprofundamento na estrutura de páginas web. Foram revisados elementos HTML mais comuns e exercitados layouts básicos com organização dos conteúdos em diferentes blocos.

- `Aula03/`  
  Desenvolvimento de atividades mais práticas e com maior exigência de organização. A aula focou em consolidar a criação de páginas visualmente mais bem montadas.

- `Aula04/`  
  Ênfase na estilização com CSS. Foram aplicados conceitos como cores, margens, espaçamentos, alinhamento, bordas e definição de elementos visuais mais refinados.

- `Aula05/`  
  Criação de páginas com diferentes tipos de conteúdo e apresentação. A aula trabalhou a organização de textos, imagens e seções para melhorar a leitura e a experiência visual.

- `Aula06/`  
  Revisão de conteúdos anteriores com exercícios de fixação. Foram realizados desafios envolvendo listas, estrutura de páginas, formatação visual e organização geral da interface.

- `Aula07/`  
  Aprofundamento no uso de CSS e no planejamento visual de páginas. Essa aula reforçou a importância da estética e da estrutura na criação de sites mais profissionais.

- `Aula08/`  
  Continuação de exercícios com foco em layout e organização. Os conteúdos ficaram mais próximos de aplicações reais no desenvolvimento web.

- `Aula09/`  
  Prática de desenvolvimento com maior atenção aos detalhes estéticos e à composição visual das páginas. A aula foi importante para consolidar o domínio de HTML e CSS.

- `Aula10/`  
  Reforço dos conhecimentos anteriores com atividades mais completas. Essa etapa ajudou a revisar o que já foi aprendido e preparar o aluno para tarefas finais mais elaboradas.

- `Aula11/`  
  Aula de consolidação e finalização dos exercícios. Foi aplicada uma revisão mais ampla dos conteúdos da disciplina, com foco na organização do código e na apresentação visual.

### 🚀 Projeto

- `Projeto/`  
  Pasta que reúne a aplicação web desenvolvida ao longo da disciplina. O projeto foi construído com base nos conceitos aprendidos em aula e representa a prática mais completa de criação de páginas com HTML e CSS.

### 🧪 Somativa

- `Somativa/`  
  Contém atividades avaliativas e exercícios de revisão, utilizados para verificar a aprendizagem e a capacidade de aplicação dos conceitos finais da disciplina.

### 🖼️ Wireframes

- `Wireframes - Projeto SC/`  
  Pasta com esboços e layouts visuais do projeto. Esses arquivos ajudam a planejar a estrutura da interface antes da construção final das páginas.

## 🧩 Tecnologias Utilizadas

- HTML5
- CSS3
- Navegador web

## ▶️ Como Usar

1. Abra a pasta que deseja explorar, como `Aula01`, `Aula05` ou `Projeto`.
2. Localize os arquivos `.html` e `.css`.
3. Abra o arquivo no navegador ou utilize a extensão Live Server no VS Code.
4. Explore os códigos e observe a evolução dos conceitos ao longo das aulas.
